# Install and run IBX locally

The **local stack** is Bun, Next.js, Convex, and a configured AI Gateway. The repository is private and expects its environment file to stay outside version control.

## Requirements

- **Node.js 20 or newer** for the Next.js and CLI toolchain.
- **Bun 1.3 or newer** for package installation and scripts.
- **Convex deployment** for the database and server functions.
- **AI Gateway credentials** for todo generation.

## Configure the app

The **environment file** is the root .env.example copied to .env.local:

```bash
cp .env.example .env.local
```

Set the required values before opening the app:

- **CONVEX_DEPLOYMENT** selects the Convex deployment.
- **NEXT_PUBLIC_CONVEX_URL** and **NEXT_PUBLIC_CONVEX_SITE_URL** connect the browser and server.
- **AI_GATEWAY_API_KEY** authorizes generation.
- **APP_ACCESS_PASSWORD** gates the legacy password session.
- **NEXT_PUBLIC_SITE_URL** sets the canonical deployment URL.

The **optional values** include AI_AGENT_MODEL, SESSION_COOKIE_SECURE, BRI_BASE_URL, BRI_INTERNAL_API_KEY, and the reminder-email settings documented in the repository README.

## Start development

Use **two terminals** so Convex functions and the Next.js app can reload independently:

```bash
bun install
bunx convex dev
```

In a second terminal:

```bash
bun run dev
```

Open **http://localhost:3000**, enter APP_ACCESS_PASSWORD, and submit a short thought. The first successful generation confirms the auth, Convex, and AI configuration are connected.

## Install the CLI

The **recommended CLI install** uses the Homebrew tap:

```bash
brew tap egeuysall/tap
brew install --formula egeuysall/tap/ibx
ibx login
```

For machines without Homebrew, the **hosted installer** is:

```bash
curl -fsSL https://ibx.egeuysal.com/install.sh | bash
```

The **browser login** creates a scoped CLI API key. Automation can skip the browser with ibx login --api-key iak_...; see the [CLI guide](../guides/cli.mdx) and [API-key guide](../guides/api-keys.mdx).

## Verify a first run

The **smallest smoke test** is:

```bash
ibx add "write the first local IBX task" --no-auto-schedule
ibx todos list --view today
```

If the command succeeds but the web view is stale, **refresh** after the queued prompt flush completes. If generation fails, inspect the server terminal and verify AI_GATEWAY_API_KEY before changing application code.
