# Turn thoughts into executable todos

**IBX** is an offline-first task execution app that turns one raw thought into a small, scheduled set of actionable todos.

<Tip>
**Start here:** run the web app locally, capture one thought, then use the API or CLI when the workflow needs automation.

## The core workflow

1. **Capture** a thought in the prompt input, CLI, Shortcut, or API.
2. **Queue** it locally when the browser is offline.
3. **Generate** at most 30 actionable todos with dates, priorities, recurrence, and optional time blocks.
4. **Review** the today, upcoming, and archive views.
5. **Execute** with status changes, notes, attachments, Bri publication, and reminders.

The **same owner-scoped data model** powers the web app, CLI, Shortcut, API, Convex backend, and optional Bri integration.

## Production surfaces

- **Web:** https://ibx.egeuysal.com
- **API:** JSON routes under https://ibx.egeuysal.com/api
- **CLI:** the ibx binary with browser login or an iak_ API key
- **PWA:** installable shell with local IndexedDB state
- **Shortcut:** hosted at https://ibx.egeuysal.com/shortcuts/ibx-capture.shortcut

<Check>
**Keep credentials server-side:** API keys are for trusted runtimes, not browser bundles, public Shortcut exports, or committed files.
</Check>
